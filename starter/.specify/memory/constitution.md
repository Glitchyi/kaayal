# Kaayal Constitution

## Principles
1. **One actual phone call before features.** The milestone is a verifiable live inbound call and audible OpenAI-backed reply.
2. **Provider contracts over assumptions.** Verify current official Sarvam tool schema, language/voice capability and OpenAI API signatures.
3. **Privacy by default.** Secrets server-side; minimal logs; no transcript or caller-number storage by default.
4. **Small and testable.** Minimal FastAPI and mocked tests; no database required.
5. **Phase gates.** No operator, booking or callback work until Phase 2 scope is clarified and approved.
6. **Proof rather than polish.** Report real tool invocation trace and audible call outcome; no invented demos.
