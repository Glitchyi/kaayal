# Kaayal Brand Guidelines (provisional)

## Naming
- **Kaayal (കായൽ)** = product/service. Malayalam for "lake/lagoon."
- **Paayal** = the voice-agent persona callers hear. Never conflate the two.
- Wordmark: `Kaayal (കായൽ)` — Latin + Malayalam, set in Fraunces.

## Voice & tone
- Plain verbs, sentence case, active voice, second person ("Your boats", "Confirm").
- Errors say what happened + what to do; they don't apologize.
- Statuses are honest: a pending request is never styled like a confirmed booking.
- Malayalam copy must be natural, reviewed by a Malayalam speaker before launch.

## Color usage
- Ivory is the default background everywhere — never pure white, never dark mode (yet).
- Teal is the only primary interactive color; lagoon for text hierarchy; sand sparingly as accent (card spine, warn-ish badges).
- Danger `#7A2E2E` only for destructive/block actions.

## Do / Don't
- DO use real operator data, `verified_at` honesty flags, and restrained typography.
- DON'T use stock Kerala imagery as fake inventory, emoji as icons, or invented prices/reviews.
- DON'T introduce new colors, fonts, or shadow systems outside `app/ui.py` tokens.
